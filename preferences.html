Folder locations: enter a full path starting with / or ~/. The folder must already exist. To pick a folder in a dialog instead, play a video and choose Plugin > Set Folder 1… or Set Folder 2… in the menu bar.
Shortcuts: write the modifiers and the key joined with +, for example Ctrl+1, Alt+k or Meta+Shift+m. Modifiers are Ctrl, Alt (Option), Shift and Meta (Command). Leave a field empty for no shortcut.
Changes take effect when you return to the player window.
